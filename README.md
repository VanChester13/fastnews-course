# FastNews

Учебный проект FastNews для курса по HTML и CSS. Он включает в себя файлы финального проекта, а также изображения.

## Структура

- `images` — изображения для проекта
- `final-project` — итоговая версия проекта

Проект постепенно дорабатывается по ходу курса: от базовой HTML-разметки до оформленной страницы с использованием CSS, Flexbox и Grid.

## Как использовать изображения

Скачайте папку `images` и поместите её в папку своего проекта рядом с HTML-файлами.

Например:

```text
project/
├── index.html
└── images/
    ├── logo.png
    ├── profile.png
    ├── spacex.png
    ├── ram.jpg
    └── dune-3.jpg

## Как использовать финальный проект

Скопируйте файлы из папки `final-project` в отдельную папку проекта.

Папка `images` должна находиться рядом с файлами `index.html`, `space.html`, `technology.html`, `cinema.html` и `index.css`.

Структура проекта должна выглядеть так:

```text
project/
├── index.html
├── space.html
├── technology.html
├── cinema.html
├── index.css
└── images/
